# 🗨️ Chat App
## A Real-Time Messaging Application
***
A sleek and modern chat application built with **React** and **Firebase**, offering secure user authentication, seamless image sharing, and a smooth, interactive messaging experience.

### ✨ Features

- ✅ **User Authentication (Firebase Auth):**  
  Secure authentication with user ID, email, and password. Users can easily sign in and access their accounts. Profile pictures can be uploaded using **Cloudinary** for enhanced personalization.  
  ![Sign In](https://raw.githubusercontent.com/iamdhruvrathi/react-firebase-chat/refs/heads/starter/project_scrennshots/SignIn.png)  
  ![Log In](https://raw.githubusercontent.com/iamdhruvrathi/react-firebase-chat/refs/heads/starter/project_scrennshots/LogIn.png)
#
- ✅ **Add New Users:**  
  Easily add new users to your chat list by clicking the '+' icon. The interface ensures smooth navigation and quick access to conversations.  
  ![Add New User](https://github.com/iamdhruvrathi/react-firebase-chat/blob/starter/project_scrennshots/addUser.png)
#
- ✅ **Home Page (Chat List):**  
  View all chats, both read and unread, at a glance. The chat list is updated in real-time using Firebase’s data sync. Users can search for specific contacts or messages using the built-in search feature.  
  ![Chat List](https://github.com/iamdhruvrathi/react-firebase-chat/blob/starter/project_scrennshots/heroPage.png)  
  ![Unread Messages](https://github.com/iamdhruvrathi/react-firebase-chat/blob/starter/project_scrennshots/newMsg.png)
#
- ✅ **Real-Time Messaging:**  
  Engage in live conversations with instant message syncing powered by **Firestore**. The state is efficiently managed using **Zustand**, while **Emoji Picker** enhances user interaction with expressive content.  
  ![Chat Box](https://github.com/iamdhruvrathi/react-firebase-chat/blob/starter/project_scrennshots/realTimeMsg.png)
#
- ✅ **Image Sharing:**  
  Share images effortlessly using **Cloudinary** for uploads and storage. Images appear neatly in chat boxes and detail sections, providing a visually appealing experience.  
  ![Image Sharing](https://github.com/iamdhruvrathi/react-firebase-chat/blob/starter/project_scrennshots/shareImage.png)
#
- ✅ **Block / Unblock Users:**  
  Protect your privacy by blocking or unblocking users. Blocked users will see a locked chat interface, preventing further communication until unblocked.  
  ![Block User](https://github.com/iamdhruvrathi/react-firebase-chat/blob/starter/project_scrennshots/blockUser.png)  
  ![Blocked User](https://github.com/iamdhruvrathi/react-firebase-chat/blob/starter/project_scrennshots/blockedUser.png)
